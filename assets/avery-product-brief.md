# Avery｜AI 求职工作空间 · 产品摘要

作者：范炜乾｜AI 产品经理方向｜南昌大学 2027 届

## 用户与问题
面向校招、实习与毕业初期求职者，连接散落在文档、网站和表格中的资料、简历、岗位和申请记录。问题定义来自场景拆解与项目 PRD，尚未提供系统访谈与规模化用户数据。

## 我的职责与当前阶段
独立进行产品设计与实现。产品持续开发中，当前重点为核心链路稳定性和小范围试用准备。

## 核心流程
整理真实经历档案 → 针对 JD 优化简历 → 保存岗位 → 用户授权的申请操作 → 跟进进度。

## 关键产品决策
1. 事实与表达分离：以确认过的档案作为来源，缺失硬事实交给用户确认。
2. 分场景授权：场景限定工具范围，确认策略约束关键写入和外部动作。
3. 执行成功需要证据：内容质量使用语义评估；浏览器成功依据测试最终状态、事件与回执。
4. 异常要有出口：登录、验证码、冲突信息、结果未知交给用户接管，不自动宣称成功。

## 评估与下一步
优先验证首次任务完成漏斗、完成耗时、人工修正、异常接管与错误提交。比较手动流程和 Agent 工作流的耗时、成本和复用情况。以上属于后续验证计划，不是已经取得的增长或效率成果。

## 证据与适用范围
作品集截图来自真实产品教程，资料为虚构示例。2026-08-28 的历史内部基线只代表固定测试集，不代表真实网站成功率。现阶段未报告商业化、用户增长或 offer 转化结果。
